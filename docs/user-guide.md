## Creating a new Employee Record

1. Click **Employees**.
2. Click **New Record**.
3. Enter employee details.
4. Click **Save**.

### Example Data

```json
{
"employeeId": 1001,
"firstName": "John",
"lastName": "Smith",
"dateOfBirth": "08/16/2000",
"department": "Admin",
"hireDate": "08/17/2026",
"payPeriod": "Weekly"
}
```
